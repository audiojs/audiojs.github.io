Audio utilities

Each one runs in your browser on an open-source audiojs package. Nothing is uploaded.

  • Extract audio from video
    Video → MP3, WAV, FLAC, OGG, Opus, AAC
    @audio/decode · @audio/encode
  • Audio converter
    MP3, WAV, FLAC, OGG, Opus, AAC, M4A in any direction
    @audio/decode · @audio/encode
  • Loudness meter and normalizer
    LUFS, true peak, loudness range; normalize for Spotify, YouTube, podcasts
    @audio/loudness · @audio/dynamics
  • Noise remover
    Background noise, hum, clicks, wind, plosives, reverb
    @audio/denoise
  • Key and BPM finder
    Musical key, Camelot code, tempo, chords
    @audio/mir · @audio/beat
  • Vocal remover
    Karaoke track or isolated vocal from a stereo mix
    @audio/vocals
  • Pitch and tempo changer
    Transpose semitones, change speed without changing pitch
    @audio/shift · @audio/stretch
  • Tuner
    Chromatic tuner for guitar, bass, violin, voice
    @audio/pitch · @audio/note · @audio/mic
  • Audio recorder
    Record from the microphone, save as MP3, WAV, FLAC, Opus
    @audio/mic · @audio/encode
  • Spectrogram
    Frequency-over-time image of any recording
    @audio/stft · @audio/spectral
  • Room and speaker measurement
    Frequency response, reverb time (RT60), latency, via a sine sweep
    @audio/measure · @audio/synth · @audio/mic

Why these run on your device

audiojs is a set of JavaScript and WebAssembly packages for decoding, encoding, measuring and processing audio. The same packages power these pages: @audio/decode reads the file, the tool's package does the work, @audio/encode writes the result. No server sees your audio, so there is no size limit, no queue and nothing to delete. Every page links the package it demonstrates; the code is on GitHub and npm.
